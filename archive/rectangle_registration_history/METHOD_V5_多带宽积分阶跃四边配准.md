# v5：多带宽积分阶跃四边配准（冻结版）

冻结日期：2026-08-31  
证据等级：Level 3

## 修订依据

v4 的多尺度梯度联合方法仍有 28/200 个硬失败，且最浅四分位失败率 32%，其他四分位 8%。冻结门限不修改，v4 全部结果保留。

v5 对全部 200 个槽统一运行。它不再依赖单像素或窄梯度峰，而是比较每条理论边界两侧固定物理带宽内的稳健高度差，从空间积分中累积浅槽信号。

## 冻结算法

- session 角度、D4、200 µm 名义边长固定；只估计中心；
- 在 270 µm 局部 canonical 图上使用 0.75 µm 固定平滑；
- 候选中心为初始化中心 ±20 µm，步长 0.25 µm；
- 对每条理论边，分别计算边外高度中位数减边内高度中位数；
- 同时使用 3、5、8、12 µm 四个冻结带宽，边界两侧保留 0.75 µm gap，避免把插值后的陡变像素当成全部证据；
- 四边对比以局部外部参考面的 `1.4826×MAD` 无量纲化，负证据截为零；
- 左右联合决定 x，上下联合决定 y，任何单边不能独自决定中心。

## 分块 bootstrap

中央 140 µm 切向带固定分为 8 块。每个带宽使用固定种子进行 64 次有放回重采样，共 256 个中心估计。主中心为全部估计中位数。记录每轴 MAD、2.5–97.5% 区间和多峰性。

## 冻结门禁

沿用 v4 的联合证据与不确定性门禁：总证据 `<8` 或任一轴证据 `<3` 为 STOP；总证据 `8–12` 为 REVIEW；任一轴 95% 区间跨度 `>12 µm` 或 MAD `>3 µm` 为 STOP，分别在 `6–12 µm`、`1.5–3 µm` 为 REVIEW；满足预注册多峰判据为 STOP；搜索边界命中为 REVIEW；paired 冲突为成对 STOP。

## 表述限制

bootstrap 区间是分块和带宽扰动下的重复性，不是绝对误差。v2–v5 方法间中心差只作 QA；没有独立真值时，证据等级保持 Level 3。

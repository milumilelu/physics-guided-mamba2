# v3：受约束四边稳健配准（冻结版）

冻结日期：2026-08-31  
适用对象：矩形加工区 Phase A 重新配准  
证据等级：Level 3（纯形貌配准）

## 修订原因

v2 使用固定权重的 region/edge 组合目标。数值收敛加密后，178 个纳入样本中有 89 个样本在三组预注册权重下中心跨度超过 3 µm。该敏感性与加工深度基本无相关，表明 region 与 edge 对“中心”的定义存在广泛分歧，不能通过放宽阈值或回退粗采样解决。

v2 全部指标、输出和失败门禁继续保留，不覆盖、不删除。v3 在运行真实结果前冻结如下规则。

## 固定量与唯一优化量

- 固定每个 session 的连续角度 `theta_session_deg`；
- 固定人工确认的 D4 变换；
- 固定名义边长 200 µm；
- 单样本只估计中心 `(center_x_um, center_y_um)`；
- paired 槽继续使用互斥左右搜索域、原始 CAG 名称顺序与最小中心间距约束。

## 四边检测

1. 使用已经冻结的 coarse plane 去除大尺度倾斜。
2. 以不进入目标函数的连通域中心作为局部取样初始化。
3. 按固定 session 角度建立 270 µm 局部 canonical 网格。
4. 在距角部至少 30 µm 的中央带内，对法向梯度取稳健中位剖面。
5. 根据“外部高、加工区低”的既定高度符号，分别使用：左边 `-dH/du`、右边 `+dH/du`、上边 `-dH/dv`、下边 `+dH/dv`。
6. 每条边只在名义位置 ±20 µm 的冻结窗口内搜索；峰值位置用 ±3 µm 正响应质心细化。

## 200 µm 约束下的联合中心

四条观测边分别给出中心候选：

```text
left + 100, right - 100, top + 100, bottom - 100
```

同轴两个候选按边缘 SNR 截断权重联合，得到唯一中心。region score、旧 edge score 和 v2 三权重中心只作为 QA 对照，不参与 v3 主中心。

## 冻结门限

- 每条边 SNR `< 3`：STOP；`3–5`：REVIEW；
- 左右或上下观测宽度必须位于 `180–220 µm`，否则 STOP；
- 四边相对受约束 200 µm 方框的残差 `>10 µm`：STOP；`4–10 µm`：REVIEW；
- 中心触及预定义搜索域边界：REVIEW；
- paired 槽顺序或最小间距冲突：成对失败。

## 科学表述边界

v3 没有独立物理真值或双人标注真值。因此只允许报告配准重复性、四边一致性、残差、参数扰动稳定性和人工 QA 通过率；禁止将 v3 与 v2 的中心差或四边拟合残差表述为绝对配准误差。

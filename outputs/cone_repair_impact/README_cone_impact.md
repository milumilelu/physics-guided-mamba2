# 圆锥伪影对观测算子的偏差量化（raw vs repaired）

## 方法
同一组跑两遍 `extract_one`：开启圆锥修复（repaired）与关闭修复（raw，圆锥留在点云里）。
其余管线（参考平面、阈值、剖面提取、线宽/线深估计）完全一致，故差值即圆锥去除对观测算子
Y_line=[W_line, D_line] 的净影响。

## 聚合（15 组可比，全部 status=ok）
- **线深 D_line**：均值 |rel| = 10.78%，有符号均值 = +10.10%（正 = 圆锥使线深变深，方向一致）
- 最大 |rel 线深| = 35.78%（group 48）；|rel|>5% 的组 **8/15**，>10% 的组 **7/15**（组 19/34/43/44/48/94/101）
- 绝对偏差最大 group 19 达 +2.01 µm、group 94 达 +1.59 µm

## 线宽 W_line（注意 group 60 是异常值，需单独处理）
- 全部 15 组均值 |rel| = 3.32%，但被 group 60 的 −38.8% 拉高；该组为 **discrete 模式、信号极少（仅 3 锥、sigma=0）**，线宽异常是自身提取不稳定，非圆锥效应。
- **剔除 group 60 后，14 个连续组**：均值 |rel| = 0.79%，最大 5.88%（group 44），>5% 仅 1/14。
- 结论：**连续模式下线宽对圆锥基本稳健（亚 1% 量级）**；group 60 这类离散/低信号组需目视 QC，不能把线宽异常归因于圆锥。

## 解读
- 圆锥是**向下尖刺**，把局部深度人为加深，故 raw 的 D_line 普遍 >= repaired（散点在对角线下方），方向一致且物理自洽——修复是"把人为加深填回真实面"，属去偏而非改形。
- **线深是圆锥的主要受害量**：约半数组偏差 >10%、最大近 36%，因此圆锥去除是观测算子 Y_line 中 D_line 的**必需前置清洗步骤**，否则会系统性高估烧蚀深度。
- 线宽在连续组几乎不受影响，圆锥去除对 W_line 必要性低；但对离散/低信号组，修复可能改变不稳定的提取结果，应单独目视复核。
- 偏差量级证明：圆锥去除不是"锦上添花"，而是 D_line 观测有效性的前提。

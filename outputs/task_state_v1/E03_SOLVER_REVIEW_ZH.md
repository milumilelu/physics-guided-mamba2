# E03 求解器审查与修复（2026-09-07）

结论：不认可旧版作为无条件注册的 E03 校准求解器。已修复实现错误并继续数值审查，正式校准尚未启动。单元测试通过不等于连续近似、有限 ROI 或参数搜索域通过。

## 四项决定

1. **到达序 incubation：认可原则，原实现不足。** 稀疏版在整道开始时冻结阈值与离焦，packet_cap=1 也未恢复逐脉冲状态更新。独立强反馈参考给出深度低估 13.54%。现逐脉冲刷新 d/q；密集版每次 ODE RHS 同时刷新阈值和离焦。连续 ODE 仍不同于离散脉冲递推。
2. **邻道格点：必须保留。** 它表示按实际顺序到达的不同扫描道，不是同时作用的镜像能量。新增横向和纵向窗口随离焦扩大后的重算与预算失败检查。尚不能据此断言旧校准的 delta 偏大两倍；校准并未运行。
3. **阈值漂移：有条件认可。** 对 Fth=F1[rho+(1-rho)exp(-q)]，d(log Fth)/dq=-(1-rho)exp(-q)/[rho+(1-rho)exp(-q)]，小 q 斜率为 -(1-rho)，不等价于 Δq。q 本身在当前递推中可持续增加，趋于饱和的是阈值。ΔlogFth 可控制纯物理阈值近似，但不能控制读取 q 的学习闭包误差，也不能证明连续模型与逐脉冲模型一致。现同时检查所有接受子步的 ΔlogFth、Δd/zR；失败不能补一个未经检查的尾段。
4. **三光腰：应提前参与求解器验证。** 已运行 0.874/2/3 μm × P01/P11 × 弱/强反馈的 12 格矩阵。11 格通过 1% 比较，0.874 μm/P11 强反馈失败（D 约 3.37%、A 约 2.31%）。该失败保留，未放宽阈值、删除案例或挑选光腰。

## 修复与验证

- 稀疏路径按实际脉冲更新反馈，调度包大小 1/64 结果相同；强反馈回归包含逐像素比对。
- 连续路径改为自适应 RK45，当前 d/q 参与每次速率评估，控制所有接受步和窗口扩张。此前 DOP853 在高斯远尾触发误差范数下溢警告；同容差 RK45 复跑仍复现强反馈差异，说明不是消除警告就消除了模型误差。
- 新增 simulate_sample_checked：每次密集候选与逐脉冲参考比较，误差超标或数值失败则返回逐脉冲结果并记录原因；参考失败直接报错。该接口有参考计算成本，尚不能宣称加速校准。
- 明确输出 domain_model=infinite_raster_interior_cell、finite_region_simulated=false。region_m 目前是登记信息，不会自动生成有限扫描边界或 80 μm 观测网格。
- G1 汇总移除硬编码计数/误差，验证子门 scope，并将 packet 最细比较由 8/4 改为 1/2。封存表重算最大变化 0.0604054%，仍通过；缺少显式 E00 引用的子门如实列出，不能声称完整同源链。
- AD/FD 的不稳定 plateau 标记不再自动豁免 >1% 未解释误差。
- 全套 47 项测试通过，RuntimeWarning 按错误处理。正式校准、材料参数拟合、机制结论均未执行。

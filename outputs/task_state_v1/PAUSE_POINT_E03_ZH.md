真实配方单道脉冲数最高 1.33e6（200 kHz × 3 mm/s ÷ 2 μm），逐脉冲 2D rollout
不可行。按协议 6.5"密集曝光不可承受时使用数值已验证的块模型"的出口，注册
**周期胞元求解器**：状态折叠到单个 hatch 周期（u）× 单个脉冲格点周期（φ），
利用所有像素共享同一脉冲距离集合的性质。两条路径：

- **稀疏**（dx > 0.15·w0）：逐脉冲冻结态 packet 块，packet 尺寸由预注册控制
  （ΔlogF_th、Δd/zR、束移/w）自适配；
- **密集**（dx ≤ 0.15·w0，MAIN180 中 60/180 样本）：连续域扫掠求积，保持
  逐节点 fluence/log-threshold（无 m·Ep 聚合），到达序 incubation，
  按 ΔlogF_th 控制贪心划 span（q 饱和后仍有效）。

物理开关语义与 `physics.step` 完全一致；光栅双向/回程、guard region 等
情景假设按 `scenario_assumptions` 显式登记（当前：单向、单遍起、无 guard）。

## 验证过程中发现并修复的物理 bug（重要）

1. **镜像道缺失**（影响真实校准）：初版只累加 u 本道，遗漏相邻道对中缝像素的
   贡献。密集光栅（h≤6w）下中缝处烧蚀被系统性低估。已改为 u 方向格点求和
   （|u+n·h| 全窗口）。
2. **u 双重平移**：`U + u_shift` 重复加了一次横坐标，导致横截面轮廓错位。
   已修复（u_shift 本身就是像素到该道的距离）。
3. **span 划分按 Δq**：q 饱和时 Δq 控制失效（span 永不闭合或漂移巨大）。
   已改为 Δlog F_th（阈值漂移）——小 q 时退化为协议的 Δq 控制精神，
   饱和区仍有意义。
4. 两个历史 FAIL/平凡 run 保留在会话记录中（形态同 G1 的 D-04 惯例）。

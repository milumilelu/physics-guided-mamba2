# 机理事件虚拟数据增强（独立实验）

本目录是后续预测建模实验，不属于高度图预处理、人工配准或稳定 ROI 提取。

它比较无增强、普通 LHS 虚拟样本、连续物理特征覆盖和 E1/E2/E5 机理事件选样。
虚拟标签由机理模型与训练折残差映射产生，不是实测形貌，也不得混入 200 个
真实槽的原始或修复高度数据。

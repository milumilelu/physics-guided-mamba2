## 2. P0 致命问题

### P0-1 · fig1 数字语义冲突：`1~5` 同时是「脉冲序号」和「附图标记」

- 光斑下方已有脉冲序号 `1 2 3 4 5 n-1 n`（fig1.svg 第 47–53 行）。
- 附图标记又用了 `1`（Hₙ）、`3`（uₙ）、`4`（Y_line）、`5`（Y_groove）（第 205–211 行）。
- **后果**：同一张图里 `3` 既表示「第 3 个脉冲」，又表示「激光作用条件 uₙ」——审查员和读者必然读错。这是整套图里最严重的一处。

### P0-2 · fig3 文字冲出画布右沿，被裁切

- `长期累积、空间均匀性信息`（fig3.svg 第 84 行）：12 字 × 26px = 312px，`text-anchor="start"` 起点 x=1090 → **终点 x=1402 > 画布 1400**，末尾「信息」二字被裁掉；同时超出所在框（1070..1360）**42px**。

### P0-3 · fig6 主流程线纵向贯穿文字

- 竖线 `x=160, y=488→720` 从「预测最终形貌」框（40..280, y=500..600）正中穿过，横切框内居中文字「预测最终形貌」与 `H_N`。

## 4. P2 · 附图标记体系（14 处）

### 4.1 标记是怎么来的

上一轮按你的指示「按说明书结构生成，我来取名」，我从 V7 交底书抽取 7 个实体，编成跨图统一编号：

| 号 | 含义 | 出处 |
|---|---|---|

| 2 | Zₙ 历史材料状态 | V7 第 30 行 |
| 3 | uₙ 激光作用条件 | V7 第 97 行 |
| 4 | Y_line 单线观测 | V7 第 123 行 |

| 7 | 联合目标函数 L | V7 第 145 行 |

### 4.2 为什么「看不懂」

不是你的问题——是这套标记**本身就没有承载信息的通道**。五个原因：

1. **没有图例，也没有说明书对应**。附图标记的正确用法是「图中数字 ↔ 说明书中『所述 3（激光作用条件）…』」成对出现。裸数字没有任何一个地方告诉你 3 = uₙ。
2. **6 张图 6 种摆法**，读者无从建立心理模型：

   | 图 | 摆放方式 |
   |---|---|
   | fig1 | 框内右上角 + 公式尾部 tspan（还有一处多余挂靠） |
   | fig2 | 框内右侧，紧贴框右沿 |
   | fig3 | 框内标题右尾 |
   | fig4 | 框外右上角 |
   | fig5 | 框外左上角（骑在框线上） |
   | fig6 | **写进标题当尾字**：「实测单线观测 4」「双状态门控模型 6」 |

   fig6 那种写法尤其糟——它读起来像「第 4 项 / 第 4 步」，完全不像标记。
3. **fig1 与脉冲序号 1~5 撞号**（P0-1）。
4. **字号不达标**：fig2/fig3/fig5 的标记用 fs=20，低于 README 规定的辅助说明下限 22（共 8 处）。
5. **骑在框线上**（视觉上像"钉在边框上"而不是"标注部件"）：

   | 图 | 标记 | 位置 | 状态 |
   |---|---|---|---|
   | fig2 | 1 / 2 | bbox 678..690 | 框右沿 680 → **骑线** |
   | fig3 | 4 | bbox 330..342 | 框右沿 330 → **骑线** |
   | fig3 | 5 | bbox 1360..1372 | 框右沿 1360 → **骑线** |
   | fig4 | 7 | bbox y 520..546 | 框顶沿 520 → **压线** |
   | fig5 | 1 / 2 / 3 | bbox 40..52, y 128..151 | 框左沿 40 + 框顶 150 → **双向骑线** |

### 4.3 规范判断（这点必须说清楚）

按 CNIPA《专利审查指南》的实践口径：

- 附图标记用于标注**结构部件**，且**图中出现的每个标记都必须在说明书中被引用并说明**。
- **流程图、框图、方法图一般不使用附图标记**——各方框本身已有文字标注步骤，再加数字是冗余。

而 fig2–fig6 全部是**方法流程图 / 模型框图**，方框里装的是算法步骤和数学量（Hₙ、Zₙ、uₙ、L），**不是结构部件**。给抽象变量编附图标记在专利实践里不规范，而且会带来实打实的递交风险：

> 图中标注了 1–7，但说明书里不会写「所述 1（表面形貌状态）」这种话 → 标记与说明书不对应 → 典型的补正通知书事由。

**结论：这套数字标记是上一轮我做的一个过度设计，现在复核下来是错的，建议整体撤掉。**

## 5. 建议方案

| 方案 | 做法 | 评价 |
|---|---|---|
| **A（推荐）** | fig2–fig6 全部删除数字；fig1 也不加数字，物理量直接用 `Hₙ / Zₙ / uₙ / Y_line / Y_groove` 字母表达 | 最符合规范，零递交风险，信息量不损失（字母本身就是变量名） |
| **B** | 只在 fig1 保留标记（它画的是加工过程与物理形貌，有"部件"可指），重新编号避开脉冲序号（如改用 10/11/12，或把脉冲序号改成 ①②③④⑤ 圆圈形式），并在图上加一行标记图例 | 若你确实想要"专利味"的标记，这是唯一合理的保留方式 |
| **C** | 全套保留 + 建立统一规范（fs 统一 22、统一摆框外左上、加指引线、每图底部加标记图例、V7 交底书同步增加「附图标记说明」段） | 工作量最大，且仍需说明书配套，风险最高 |

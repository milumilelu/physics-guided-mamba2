## 统一视觉语法（请按此规格改绘）

### 画布与栅格

- **画布**：宽 1400 × 高 820（统一横向矩形）。
- **顶部标题**：y=58~64，font-size **32 粗体**，深蓝 (#185FA5)。**图内不再放"图1""图2"字样**，图题与解释交给 Word 正文。
- **左右边距**：左右各 40 px。

### 框尺寸三档

| 类型 | 尺寸 | 用例 |
|---|---|---|
| 普通框 | 240 × 140（高度可微调） | 大部分输入、观测、结论框 |
| 重点框 | 240 × 200 或 280 × 320 | 联合约束、双状态同步更新、压缩观测 |
| **核心模型** | **340 × 200（仅此一档，整张图唯一最大）** | 图 4 中央递推模型 |

同类角色使用相同尺寸；不同角色必须可在视觉上区分。

### 字号（**铁律**：禁止 11、12、13 这种字号；目标实际插入 A4 160mm 宽约 7~8pt 时仍清晰）

| 用途 | 字号 |
|---|---|
| 顶部标题 | **32 粗体** |
| 框标题 / 列标签 | **28–30 粗体** |
| 模块副标题 | 28 粗体 |

**框内文字不能靠缩字号塞进去；宁可删字 / 改换行**。

| 颜色 | 用途 | 配色（浅 / 边 / 深） |

### 连线规则

- **主流程**只允许**水平直线 + 正交折线**（90° 转弯，不允许斜线、贝塞尔、巨大半圆）。
- **上下关系**：每张图最多 1 根竖向连接线（必要时）。
- **反馈线**：每张图最多 1 根外围 90° 正交折线，且只允许从"模型参数更新"指向"核心模型"。
- **同色同语义**：连线颜色与所在框主题一致；橙色只用于校准与反馈。
- **图 4**：E→H 与 I→C 反馈线均**变细变淡**（stroke-width 1.6，dasharray "6 4"），不抢主流程视觉。
- **箭头**：使用**显式 `<polygon>` 实心三角**，按 stroke-width 自适应大小，最小约 11 px。

## 箭头方案

- 本批图统一使用**显式 `<polygon>` 实心三角箭头**（不依赖 `<marker>` + `url(#id)` 引用，渲染器无关）。改绘时直接增删 `<polygon points="..." fill="..."/>` 即可。
- 颜色随所在线条 stroke 变化（蓝色线条 → 蓝色箭头；灰色 → 灰色；橙色 → 橙色）。
- 定位方法：在源文件中 grep `marker-end` 应为 0；grep `<polygon points` 应能看到若干行（每张图通常 8–16 处）。

## 单色 / 黑白改绘

将所有 fill 替换为 none，stroke 改为 #000；dashed 改为不同 dasharray；红色虚框可改为点划线。箭头 polygon 同步把 fill 改为 #000 即可。这样图 2、5、6 中的"隐变量"与"模型状态"仍可通过线型区分。

## 自检渲染命令

本机有 Chrome 时：

```bash
CHROME="/c/Program Files/Google/Chrome/Application/chrome.exe"
$CHROME --headless=new --disable-gpu --hide-scrollbars --no-sandbox \
  --user-data-dir="C:\\Users\\RZF\\AppData\\Local\\Temp\\cud_<unique>" \
  --force-device-scale-factor=1 --window-size=1400,820 \
  --screenshot=out.png "file://$(pwd)/figN.svg"
```

**坑**：`--user-data-dir` 必须用 **Windows 路径**（如 `C:\\Users\\RZF\\AppData\\Local\\Temp\\cud_xx`），且**每张图用独立目录**；否则 Chrome 回退到 new tab 页（`Requested load of chrome://newtab/ for incorrect profile type`），所有 PNG 都变成 ~26KB 空白页。

或在 Python 中用 cairosvg：`cairosvg.svg2png(url='fig1.svg', write_to='fig1.png', output_width=1400)`（本机 pip 无外网装不上，需走 Chrome 路线）。

## 箭头修复工具

若编辑过程中再次出现箭头丢失：

```bash
cd 专利/figures
python fix_svg_arrows.py
```

脚本把所有 `<line>`/`<path>`/`<polyline>` 的 `marker-end` / `marker-start` 引用替换为**显式实心三角 `<polygon>`**，并删除不再使用的 `<marker>` 定义与空 `<defs>`。已处理过的文件再次运行会输出 0 处（no-op，幂等）。本批新写的 6 张图已直接内建 polygon，不需要再跑该脚本。

### 7.2 (12:58) fig1 B 区三段式重排

- **根因**：B 区（旧版 300..700, y=80..450）单框塞入「重叠加光斑（高斯能量分布）+ 扫描方向 + 7 光斑 + 标号 1..5/n-1/n + Δx + 时间轴 + Δt + 三张状态卡片」共 12 个独立元素 + 6 段文字；与 A、C、D 三区纵向不对齐（顶部 y=130 而 B y=80）。用户报"全堆在一起了"。
- **修复**：
  - B 区扩到 `y=80..600, h=520`，纵向三段式：光斑带 (140~330) / 时间轴 (350~430) / 三状态卡片 (472~572)，两两间用 `stroke="#185FA5" opacity="0.5" dasharray="3 4"` 虚线分隔。
  - A/C/D 三区顶齐 y=80、底齐 y=600，与 B 等高（视觉重量平衡）。
  - 「扫描方向」标签从旧版 (text-anchor=end x=512 y=160) 挪到 (x=680 y=196)，箭头反向朝左指向光斑带；不让标题被压。
  - Δx 标尺 (y=290) 移出光斑带正下方，不再穿越光斑。
  - B-3 三卡片高度从 76 拉到 100，标题/波形/底部标签垂直分布更舒展。
  - B→C 与 C→D 两条主连接线统一到 y=420（视觉中心），不再穿越内容。
  - C 区追加「累积成槽 → 最终二维轮廓」收尾说明，把第 3 遍扫描与下游「矩形槽观测」显式连接。
  - D 区上下两子框各增加一行 `Y_line = [ w_line, d_line ]` 与 `Y_groove = [ d_groove, S_a, S_q, S_z ]`，把数据契约写进图。
  - 图标记 1/3/4/5 同步上移到框顶 y=100 / y=100 / y=170 / y=410。
- **二次小修**：扫描方向箭头起点再左移 16px 至 x=642 处，避免箭头与末字擦碰。
- **复检**：`audit_figs.py` fig1 字号分布 {18:16, 20:3, 22:34, 24:3, 26:9, 28:4, 32:1}，非档位残留 = 0。

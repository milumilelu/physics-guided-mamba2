# Phase 1：深度–形状分解与基础形貌探索

## 1. 目标

Phase 1 只回答一个问题：

> 去掉样本间加工深度差异后，二维残差形貌是否仍存在稳定、低阶、并随 pass 呈系统变化的组织结构？

核心区分为：

$d_i=-\operatorname{median}_{M_i}H_i(x,y)$$R_i(x,y) = H_i(x,y)-\operatorname{median}_{M_i}H_i(x,y)$

因此：

$H_i=-d_i+R_i.$

分别研究：

- $d_i$：加工深度变化；
- $R_i$：去除整体垂直偏移后的二维形状变化。

Absolute PCA 与 Residual PCA 是两个不同统计对象。

## B. Depth

计算：

```text
median_depth_um

```

其中：

$d_i=-\operatorname{median}(H_i).$

输出：

```text

depth_vs_process.png
```

只做描述性散点与分组展示，不做回归。

------

## C. Absolute PCA

对：

$H_i$

进行 PCA。

报告：

- PC1–PC10 EVR；
- cumulative EVR；
- PC1–PC6 spatial modes；
- 1–10 维重建 RMSE；
- $\operatorname{corr}(PC1,d_i)$。

输出：

```text
absolute_pca_evr.png
absolute_pca_modes.png
```

------

## D. Residual PCA

对：

$R_i = H_i-\operatorname{median}(H_i)$

进行 PCA。

报告：

- PC1–PC10 EVR；
- cumulative EVR；
- PC1–PC6 spatial modes；
- 1–10 维重建 RMSE。

输出：

```text
residual_pca_evr.png
residual_pca_modes.png
pca_reconstruction_rmse.png
```

核心问题是比较：

$PCA(H)$

与：

$PCA(R).$

------

## E. Residual PCA 稳定性

由于 200 ROI 实际来自 160 个共享高度来源，bootstrap 按：

```text
shared_height_source_id
```

重采样，同一 measurement 下的两个 ROI 共同进入或共同离开 bootstrap 样本。

重复约 200 次。

主要检查前若干 PC 张成子空间的 principal-angle 稳定性。

目的只是判断观察到的 residual structure 是否明显依赖少数样本，不设置事后通过阈值。

------

## F. Raw / repaired sensitivity

以：

```text
height_raw
```

作为正式结果。

对：

```text
height_repaired
```

重复相同 PCA 流程，只比较：

- EVR；
- 主要 residual subspace；
- pass trajectory 的总体结构。

不以 repaired 结果替代 raw。

------

## G. Repeatability sentinel

正式 DOE 49/50 为唯一完全相同工艺重复。

报告：

```text
absolute-height RMSE
depth difference
residual-shape RMSE
```

并与普通样本对距离的总体尺度作简单对照。

该样本对只作为单对重复性参照。

------

## H. N=1–4 trajectory atlas

将 60-pass 数据的 15 条 trajectory 投影到 residual PCA 空间。

生成：

```text
pass_trajectory_N1_N4.png
```

主要观察：

- N 增加时是否存在共同方向；
- 轨迹是否近似直线、弯曲或无组织；
- 不同工艺条件的轨迹是否明显不同。

本阶段只做描述，不拟合状态转移模型。

# 7. 完成条件

Phase 1 完成时应能够清楚回答：

1. 当前 200 个 ROI 中，absolute-height variance 有多少由加工深度主导？
2. 去除 depth offset 后，残差二维形貌的方差结构是什么？
3. 这些 residual modes 是否对共享 measurement bootstrap 基本稳定？
4. raw 与 repaired 是否给出一致的总体结构判断？
5. N=1–4 是否在 residual morphology space 中呈现系统性的 cross-sectional trajectory？

Phase 1 是描述性探索。

本阶段不把 PCA 维数解释为物理状态维数，不进行预测或因果推断，也不讨论 N=4→5 的机制来源。

到此停止，由结果决定 Phase 2。

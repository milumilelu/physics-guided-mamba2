## 2. Step 1 — Exploration manifest

### 2.1 读取与连接

1. 读 index CSV（200 行）→ `dataset_index, session_id, measurement_id, sample_id, status, valid_fraction, repair_fraction`。
2. 读 `annotations/sample_view_manifest.csv`，按键 `(session_id, measurement_id, sample_id)` 左连接 → `shared_height_source_id, roi_within_measurement`。
3. 读 `config/session_manifest.csv` 取各会话设计表路径；设计表用 `encoding="gb18030"` 读取，列重命名：

   | 原列 | 输出列 | 换算 |
   |---|---|---|
   | 加工顺序 | `processing_order` | 原值 |
   | 中心X / 中心Y | `x_position_um` / `y_position_um` | mm→µm（×1000，仅保留描述用） |
   | 脉宽 | `compressor_steps` | 原值；另查表得 `pulse_duration_fs` |
   | 频率 | `frequency_kHz` | 原值 |
   | 线间距 | `hatch_spacing_um` | mm→µm（×1000） |
   | 次数 | `pass_count` | 原值 |
   | 速度 | `velocity_mm_s` | 原值 |

4. `pulse_duration_fs` 由 config 内嵌标定表转换，并写入
   `pulse_duration_calibration_id = compressor_steps_to_fs_v1`、
   `pulse_duration_calibration_version = 现有数据基础说明_v2.md-§8`；
   **`compressor_steps` 原始列永久保留**，fs 列是派生列。
5. `design_group`：`zro2_60_pass` 按四元组分组编号 T01–T15（按 compressor_steps, frequency, hatch, velocity 排序）；`zro2_20_supplement` 编号 S01–S10；`zro2_120_formal` 留空。
6. 会话角色列 `session_role ∈ {formal, pass_main, pass_supplement}`，便于后续过滤。

### 2.2 硬断言（任一失败即终止）

```text
A1 index 200 行；(session_id, sample_id) 主键唯一
A2 manifest 连接 200/200 命中；shared_height_source_id 唯一值 = 160
A3 设计表行数 120/60/20；所有 compressor_steps ∈ 标定表
A4 paired 会话：measurement k 的 sample 集合 == {2k-1, 2k}，
   且对应两设计行共享 (脉宽,频率,线间距,速度)（20 补充的 次数 ∈ {5,6}）
A5 全部 status == PASS；valid_fraction ≥ 0.99
A6 49/50 两设计行五维工艺字段逐项相等
A7 60-pass 轨迹分组：恰 15 组，每组 pass_count == {1,2,3,4} 各 1 个
```

先写身份列（无深度指标）落盘 `exploration_manifest.csv`；Step 3 完成后**原地补写** `median_depth_um`、`residual_Sq_um` 两列（仍是这一个文件）。

## 3. Step 2 — 数据装配与无效像素策略

1. 读 NPZ：`height_raw`（正式）、`height_repaired`（敏感性）、`valid_mask`、`repair_mask`；断言形状 200×160×160。
2. 展平为矩阵 `H ∈ R^{200×25600}`；`valid ∈ {0,1}^{200×25600}`。
3. **NaN 策略**（确定性规则，运行时打印执行结果）：
   - 统计每行 valid_fraction 与逐像素全 200 样本共同有效像素数；
   - 若共同有效掩码覆盖 ≥ 95% 像素：PCA 与距离计算限定在该共同掩码上（最干净）；
   - 否则：在非共同有效像素处用「该像素在有效样本上的均值」填充，并打印受影响像素数。
   - 无论哪种，均记录进运行日志；当前预期走分支 1（几乎无 NaN）。
4. `H_repaired` 单独装配，同样策略，仅用于 Step 7。

## 4. Step 3 — A. Data atlas

- `dataset_atlas_global_scale.png`：200 张缩略图，20 列 × 10 行，按 `dataset_index` 排列（行块 = session），色标 vmin/vmax 取全体样本 1–99 百分位，单位 µm，附共享 colorbar；图上标注 dataset_index（稀疏标注每格序号）。
- `dataset_atlas_individual_scale.png`：同样布局，每格独立 vmin/vmax。
- 数据：`height_raw`（NaN 保持透明色）。

## 5. Step 4 — B. Depth

对每个 ROI（在有效像素上）：

```text
median_depth_um = −median(H_i[M_i])          # d_i
residual_Sq_um  = sqrt(mean(R_i[M_i]²))      # R_i = H_i − median(H_i)
```

- `depth_distribution.png`：上排 d_i 直方图 + 按 session 的箱线图；下排 residual_Sq 直方图 + 按 session 箱线图。
- `depth_vs_process.png`：d_i 对 `pulse_duration_fs, frequency_kHz, hatch_spacing_um, velocity_mm_s, pass_count` 五个散点面板，颜色区分 session；**纯描述，不拟合**。
- 完成后回写 manifest 两列（§2.2 末尾）。

## 6. Step 5 — C. Absolute PCA

对象：`H_i`（在 §3 分析掩码上，sklearn PCA 全 SVD，自动全局中心化）。

产出：
- PC1–PC10 EVR、cumulative EVR（打印 + `absolute_pca_evr.png` 条形/阶梯图）；
- PC1–PC6 空间模态（reshape 回 160×160；**符号约定**：将每张模态按「绝对值最大像素为正」翻转，保证确定性；`absolute_pca_modes.png`，发散色图 RdBu_r）；
- 1–10 维重建 RMSE（在同一中心化基准上，µm，曲线进 `pca_reconstruction_rmse.png`）；
- `corr(PC1, d_i)`（Pearson，打印）。

## 7. Step 6 — D. Residual PCA

对象：`R_i = H_i − median_i`（中位数逐样本去除；PCA 内部再中心化为常规流程）。

产出与 C 同构：EVR、cumulative、PC1–PC6 模态、1–10 维重建 RMSE。
文件：`residual_pca_evr.png`、`residual_pca_modes.png`、`pca_reconstruction_rmse.png`（absolute 与 residual 两条曲线画进同一张 RMSE 图，便于对比）。
核心对比输出：打印并保存 absolute vs residual 的 EVR 对照表（内容并入后述 CSV/日志）。

**主成分得分缓存**：`scores_abs`、`scores_res`（200×10）留内存，供 Step 9/10 使用，不落盘。

## 8. Step 7 — E. Residual PCA 稳定性（cluster bootstrap）

1. 聚类单位 = `shared_height_source_id`（160 簇：120 簇 size1 + 40 簇 size2）。
2. 重复 B=200 次（`--quick` 时 B=10）：有放回抽 160 簇 → 重建 ROI 集合 → 在 bootstrap 样本内**重新计算残差与 PCA**。
3. 对 k = 1…6：计算 bootstrap 前 k 张成子空间与全样本参照子空间的 **principal angles**（`scipy.linalg.svd(U_refᵀ U_boot)`，取最大主角，度数）。
4. `bootstrap_pca_stability.csv`：每行 = (replicate, k, max_principal_angle_deg)；文件末尾附 k=1…6 的 median / IQR 汇总行（`replicate=summary`）。
5. 不设阈值，仅描述；同时打印 EVR(前 3 PC) 的 bootstrap 分位数作辅助。

## 9. Step 8 — F. Raw / repaired 敏感性

`height_repaired` 重复 §6–§7 流程（absolute + residual PCA）。只比较三件事：

1. EVR：raw vs repaired 的 PC1–PC10 EVR、cumulative（绝对与残差两套）；
2. 主要 residual 子空间：repaired residual 前 k (1–6) 与 raw residual 前 k 的 principal angles；
3. pass trajectory 总体结构：60-pass 60 个 ROI 在两套 residual 空间 PC1–PC3 得分的逐分量相关系数，以及各轨迹 (N4−N1) 平均位移向量在两空间中的夹角余弦分布。

`height_raw` 保持正式结果；`raw_repaired_sensitivity.csv` 列：
`metric_family, detail, raw_value, repaired_value`（subspace 角度填在 raw_value 列，repaired_value 留空，family=`subspace_angle_k{n}`）。

## 10. Step 9 — G. Repeatability sentinel（49/50）

样本对：`session=zro2_120_formal, processing_order ∈ {49,50}`（经 manifest 定位 dataset_index，不硬编码行号）。

```text
absolute-height RMSE : sqrt(mean((H_49[M] − H_50[M])²))，M = 两样本共同有效像素
depth difference     : |median_depth_49 − median_depth_50|
residual-shape RMSE  : sqrt(mean((R_49[M] − R_50[M])²))
对照                  : 全部 C(200,2)=19900 个普通样本对的 residual-shape RMSE 分布
```

`repeatability_sentinel_49_50.png`：上排两个高度图并排（同一色标）+ 差值图；下排 19900 对 RMSE 直方图，sentinel 位置画竖线并标注数值。
同时打印：sentinel 在普通对分布中的百分位。

## 11. Step 10 — H. N=1–4 轨迹图

- 数据：60-pass 60 个 ROI 的 residual 得分（Step 6 的 `scores_res`）。
- `pass_trajectory_N1_N4.png` 布局：
  - 左：PC1–PC2 平面，15 条轨迹各折线连接 N=1→4（同色），N 用点大小编码；
  - 中：PC1–PC3 平面，同上；
  - 右：15 个小面板（每轨迹一帧）展示其自身 4 点轨迹形状，便于判断直线/弯曲/无组织。
- 打印描述统计：各轨迹相邻步位移向量之间的平均夹角；全体轨迹 (N4−N1) 平均位移向量两两余弦（判断是否存在共同方向）。
- 只描述。N=5–6（supplement 20 ROI）参与 PCA 总体但**不画进本图**。

## 12. Step 11 — 汇总打印（对应完成条件 5 问）

脚本结尾打印一页描述性汇总：

1. depth 主导度：`1 − Var(R_centered)/Var(H_centered)`（并给出两者绝对方差）；
2. residual 方差结构：PC1–PC10 EVR 表 + 各模态极值/空间周期简述；
3. bootstrap 稳定性：k=1…6 主角 median/IQR/max；
4. raw vs repaired：EVR 最大差值、subspace 角度范围、轨迹得分相关；
5. N=1–4 轨迹：共同方向余弦统计、直线/弯曲观察结论（描述性措辞）。

## 16. 决策记录（与任务书的偏差说明）

| 决策 | 理由 |
|---|---|
| manifest 坐标列命名 `x_position_um/y_position_um` | 任务书列名未带单位；设计表为 mm，显式写 µm 防止误读 |
| 补充列 `roi_within_measurement, session_role, pulse_duration_calibration_id/version, valid_fraction, repair_fraction, design_group` | 任务书允许「至少包含」；标定溯源是 §8 的明确要求 |
| 20 补充 ROI 进入总体 PCA/atlas/depth，但不进入轨迹图 | 任务书定义主数据为全部 200；轨迹仅限 60-pass N=1–4 |
| design_group 对 120 正式留空 | 119 个唯一组合编号无分析用途，避免误导 |
| 图内文字用英文 | 规避 matplotlib 中文字体缺字风险；中文结论在汇报中给出 |

## 17. 边界重申

- 不做回归/模型选择/维数物理诠释；不讨论 N=4→5 机制；
- PCA 维数只报告 EVR 与子空间稳定性；
- raw 是正式结果，repaired 仅敏感性；
- 全部产出可由一条命令重新生成，种子固定。

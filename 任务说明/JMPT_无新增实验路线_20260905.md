# JMPT 论文收敛路线（不新增实验）

2026-09-05。按用户粘贴的路线与本次修正要求登记；适用于后续工作。历史 Phase2.8 v2.1 与 repeatability 设计保留作研究记录，不再作为当前下一步指令。此文没有把已知结果重新宣称为事前假设。

1. 当前修正：2.8r1 关闭审查中的六项代码/契约/表述问题，保留旧产物。物理约束、完整相位积分、median 选择、OOF/R²、phase realization 表述和稳定 array transfer 分别验证。
2. 论文统计补全：以 r1 OOF 为统一基础，新增 Route P cross-fitted spline effect maps（raw inputs、src/proc、formal-only sensitivity）；全通道 error atlas（同一误差定义和邻域，Moran permutation、coverage、模型 sensitivity）；双向 P/T conditional additions 与 cross-fitted residual coupling。新增分析另行版本化，不用历史不同协议分数拼图。
3. Effect maps 只能解释为给定输入支持域与模型下的条件预测关联；N=4→5 与 session 混杂、f 与 pulse energy 耦合均不可用建模消除。不同 delta_h 不自动证明两个目标可独立控制。
4. Physics feasibility 必须先写方程、初边值条件、材料参数来源及可辨识范围，再实现求解器。固定物理量、可校准有效参数与不可辨识参数分别登记；已确认平均功率不自动验证吸收系数或绝对温度。旧 measured-kernel bridge 不是 PDE/PINN benchmark。
5. 分层验证：独立数值 solver → unique-condition grouped 单轨验证 → 原 DOE 域内 virtual morphology descriptors → 双目标设计。solver 或单轨验证失败则停止正文应用扩展，不追求让 gate 转正。
6. 200 条现有数据已用于 discovery。以后划出的 subset 只能作为披露既往使用情况的 retrospective/internal validation；不称独立 confirmation。候选选择不能使用评估标签；nearest condition 必须事先定义距离、阈值和容差，并报告偏差。
7. 新增 repeatability / confirmation 实验列入 future work；不据当前单对重复推断不可约噪声、工艺不控制 phase 或误差下限。

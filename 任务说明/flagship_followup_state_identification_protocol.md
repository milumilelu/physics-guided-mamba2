# 旗舰实验方案：深度何时是充分的加工状态？

## 研究问题

给定当前加工深度 `D_t`、表面形貌观测 `M_t` 和下一步工艺 `U_{t+1}`，历史加工序列 `H_t` 是否还会改善对下一步去除量 `ΔD_{t+1}` 的预测？结论只针对预先限定的材料、视场、测量协议和两种后续配方。

## 设计结构

`不同前期历史 H_t → 当前观测 (D_t, M_t, F_t, S_t) → 固定后续配方 U_A/U_B → ΔD 与形貌变化`

- `D_t`：外部平面参考的中位深度，单位 µm。
- `M_t`：中心化形貌；主分析使用预先注册的少量谱指标（建议 `A_med`、`ilr_z1..z4` 中最多 2 个、`rms_DCT_8_16_um`、`rms_DCT_32_64_um`），完整 17 维描述符只作敏感性分析。
- `F_t`：焦点位置/离焦量及测量时间戳。
- `S_t`：必要的材料、热状态和暂停信息；若不能测量，必须登记为未知而不是假定相同。
- `U_A/U_B`：两种预先固定的后续工艺配方，覆盖一个低剂量和一个高剂量响应探针；后续配方不得根据 `M_t` 选择。

## 前期历史与分组

构造 4–6 个前期历史族，每族包含 3–4 个序列，使当前深度分布有重叠但形貌/谱组成存在差异。历史族应至少跨越：

1. 低/高 pass 数；
2. 两个不同的频率—速度组合；
3. 一个不同离焦路径或扫描方向条件（若设备允许）。

每个历史族内随机化样品和测量顺序。历史组合、样品编号和设备批次进入冻结登记表；不能在看到结果后重定义“相似深度”或“不同形貌”。

建议的最小首轮规模是 24 个独立位置（4 个历史族 × 3 个位置 × 2 个后续配方），另加 6 个重复位置用于测量重复性。这个规模用于估计噪声和效应量，不预先宣称能排除任意实际效应；正式样本量根据首轮噪声估计和预注册的最小有意义差异（MID）更新。

## 当前观测与暂停登记

每个位置在后续加工前完成两次独立形貌测量（同一仪器、重新装夹一次），记录：

- `D_t`、`M_t`、ROI、像素尺寸、有效掩膜和配准质量；
- 焦点位置、环境温度、样品温度或可用热状态代理；
- 从上一次激光照射到测量、从测量到后续加工的暂停时长；
- 是否重新装夹、是否改变扫描方向、操作者和设备批次。

后续加工后立即重复形貌测量，得到 `D_{t+1}`、`M_{t+1}` 和 `ΔD = D_{t+1}-D_t`。若逐 pass 离线测量引入长暂停，暂停时长必须作为研究条件登记；连续加工状态与冷却后状态不能混为一个结论。

## 预注册的比较模型

对每个后续配方分别拟合，并使用按历史族/实验批次留出的外层验证：

```text
G0: ΔD ~ D_t + U_{t+1}
G1: ΔD ~ D_t + Z_M(M_t) + U_{t+1}
G2: ΔD ~ D_t + Z_M(M_t) + H_t + U_{t+1}
```

其中 `Z_M` 是冻结的少量可解释谱变量；`H_t` 只在 G2 中加入，且不得包含由 `D_t` 或 `M_t` 反推得到的派生变量。主指标为历史族留出集的 MAE、RMSE 和配对风险差；报告 95% 区间及 MID，而不是只报告显著性。

## 判定规则

- `G1−G0` 在两个后续配方、留出历史族和预设 MID 下均稳定改善：支持“深度不是充分状态，形貌提供响应相关观测”。
- `G2−G1` 不超过 MID：在限定任务和观测下，`D_t + Z_M` 可作为近似充分预测状态；不能推广为材料内部不存在其他状态。
- `G2−G1` 超过 MID：当前观测仍遗漏历史相关状态，应优先增加可测状态或改变观测时间尺度，暂缓 Mamba/长记忆模型。
- G1 只在一个配方改善：结论限定为任务特定响应探针，不能声称形貌普遍补充状态。
- 所有模型差异都落在 MID 内：报告为不确定性和测量边界，不写成“没有效应”。

## 噪声、共享误差与质量门

先用 6 个重复位置估计形貌测量误差、深度误差和重复加工误差。由于 `ΔD = D_{t+1}-D_t` 与输入共享 `D_t` 测量误差，主分析同时报告误差协方差敏感性；不能把 D1 残差方差直接当作实验重复性。

任一位置若 ROI 配准失败、有效面积不足、暂停日志缺失或深度超出训练支持范围，进入质量表并按预先规则剔除；不得按结果选择性剔除。

## 因果声明边界

该设计首先识别“当前形貌是否是未来响应的增量预测状态”。前期历史同时改变形貌和潜在缺陷/相态/热状态，因此即使 G1 改善，也不能单独声称形貌本身具有因果作用。若要做因果干预，需另行设计只改变形貌而保持相关材料状态可比的干预实验。

## 预先停止规则

- 任何关键测量或配准质量门失败：暂停扩展样本，先修复流程。
- 两个后续配方均无法达到预设深度重叠区间：停止状态辨识比较，先重做历史构造。
- 重复测量误差大于 MID 的 50%：先优化计量与 ROI，不增加模型复杂度。
- 只有在 G1/G2 的留出验证完成后，才考虑 GRU/SSM/Mamba 作为表示模型敏感性分析。
